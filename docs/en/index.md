# Grammar Notebook

Short English grammar lessons for learners starting again from the basics, ordered by the 9 chapters of *Giải thích ngữ pháp tiếng Anh* (Mai Lan Hương – Hà Thanh Uyên). Each lesson keeps only what you need to speak and write correct sentences, and every rule comes with examples. Example sentences keep their Vietnamese translation.

[See the study path →](/en/lo-trinh)

## Contents

| Chapter | What it covers |
|---|---|
| [1. The Parts of Speech](/en/1-tu-loai/) | The foundation of every sentence: what kind of word each word is, where it goes and how it changes. |
| [2. Tenses](/en/2-thi/) | How verbs change for time (present, past, future) and for how an action unfolds. |
| [3. Clauses and Phrases](/en/3-menh-de-cum-tu/) | Joining ideas into longer sentences: relative clauses, purpose, cause, result, contrast, wish. |
| [4. Sentences](/en/4-cau/) | Word order, asking questions, negatives, question tags and emphasis. |
| [5. Conditional Sentences](/en/5-cau-dieu-kien/) | Talking about real conditions and imagined ones. |
| [6. Indirect Speech](/en/6-loi-noi-gian-tiep/) | Reporting what someone else said. |
| [7. Passive Sentences](/en/7-bi-dong/) | Putting the thing affected first instead of the person doing the action. |
| [8. Expression of Quantity](/en/8-so-luong/) | Saying how much or how many: a lot, a little, all, each, both. |
| [9. Word Study](/en/9-tu-vung-hoc/) | Building words with prefixes and suffixes; word forms, idioms and style. |

There is also a [vocabulary section](/en/tu-vung/) with 3000 core words, 500 common phrases and IT words for mobile developers.

## How to read a lesson

::: info FORMULA
The light blue box holds formulas and sentence patterns.
:::

::: warning IMPORTANT
The yellow box is a rule to remember.
:::

::: danger COMMON MISTAKES
The red box shows typical mistakes with the correct version.
:::

::: tip TIP
The green box is a quick memory trick or an extra note.
:::

Examples always look like this: the English sentence, the grammar point in **bold**, and the Vietnamese translation underneath.

- She **works** in a bank.<br>*Cô ấy làm việc ở ngân hàng.*

## Symbols

| Symbol | Meaning |
|---|---|
| S | Subject |
| V | Base form of the verb |
| V2 / V-ed | Past form (column 2 of the irregular verb table) |
| V3 | Past participle (column 3) |
| O | Object |
| N · adj · adv | Noun · adjective · adverb |
